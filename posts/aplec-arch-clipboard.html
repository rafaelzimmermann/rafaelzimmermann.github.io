Aplec: A Simple Clipboard Manager for My Arch Linux Setup

March 31, 2026 2 min read

Aplec is a simple clipboard manager I wrote for my Arch Linux setup. It keeps a short history of copied text and gives me a keyboard-driven way to retrieve it.

The interaction is small: open the popup, move through previous entries, press Enter to copy one back to the clipboard, then paste it where it belongs. Escape closes the popup without changing the clipboard.

Implementation

A background daemon polls wl-paste every 500 milliseconds, deduplicates entries, and keeps the last 50 in a history file. The popup reads that file when it opens and uses wl-copy to restore the selected entry.

Aplec targets Wayland compositors with the layer-shell and data-control support it needs. My setup uses Hyprland. The project is written in Rust and relies on wl-clipboard for clipboard access.

The popup’s placement and colours are configurable.

Local history

The history persists on disk, so it survives the popup closing. That also means copied text can remain there after it leaves the active clipboard.

The history file uses owner-only permissions. That limits access by other users on the machine, but it does not make the contents encrypted or turn the tool into a password manager.

A recent startup fix

A recent Hyprland upgrade exposed an assumption in the service setup. The daemon was attached to graphical-session.target, but the start-hyprland launcher did not activate that target. The clipboard history stopped updating.

The fix moved the service to default.target and made the daemon discover the Wayland socket as it runs. This lets it cope with the compositor environment becoming available after the service starts.
