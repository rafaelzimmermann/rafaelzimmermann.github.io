Pontet: Getting Files to My 3D Printer over Wi-Fi

April 4, 2026 2 min read

My 3D printer does not support file transfers over LAN or Wi-Fi. I wrote Pontet to work around that limitation.

The idea is to put a Raspberry Pi Zero W between my network and the printer. I mounted a shared directory from my NAS on the Pi, so I can just drop a print file into that folder. The Pi syncs it to the USB storage the printer sees.

How it works

Pontet uses Linux USB gadget mode to present a disk image as a USB mass-storage device. From the printer’s side, the interface is still USB. The networking happens on the Pi.

My setup uses an SMB share on the NAS as the source directory. I do not need to copy files directly to the Pi: I save them in the shared folder. Pontet also supports copying files to a local directory on the Pi using SCP if you do not have a NAS.

What happens when a file arrives

A watcher checks the shared directory every 30 seconds. When it detects a change, a sync script detaches the USB gadget, updates the FAT32 disk image, and reattaches it.

The printer sees a USB drive that is refreshed periodically. The drive briefly disconnects during a sync. Transfers should therefore happen while the printer is not reading from it, rather than during an active print.

Setup

The repository includes an image-flashing script and an Ansible playbook for configuring the Pi. The latest fix deals with Wi-Fi radio initialization during provisioning: having network credentials written to disk is not enough if the radio is still blocked.

I drop a print file into the NAS folder. Pontet syncs it, and I can select the file on the 3D printer and start printing.
