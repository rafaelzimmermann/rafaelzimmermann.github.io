gitplay: Watching a Coding Agent Work

October 11, 2026 2 min read

I run coding agents on my repositories, and I kept doing the same thing: switch to another terminal, run git diff, run it again, run it again. That is a poor way to follow an editing session that is still in progress.

So I wrote gitplay. It watches a repository's working tree and prints changes as a live, rolling diff in the terminal. Additions, deletions, and context scroll by as files change, commits show up with hash, branch, and subject, and a footer keeps the repository path and current branch visible. Press q to leave.

By default it shows each change since the last update; --cumulative switches to the full uncommitted change against HEAD. Debounce window, diff context, and display pace are adjustable. It respects .gitignore and .git/info/exclude, and skips hidden files, Git internals, editor temporaries, and anything that is not UTF-8.

It is a single Rust binary:

git clone https://github.com/rafaelzimmermann/gitplay.git
cd gitplay
./install.sh

gitplay            # from inside a repository
gitplay /some/path # or pointed at one

Nothing more to it than that. It does one thing: you point it at a path, and you can see what the agent is doing.
